切换通联场景

先看状态是否一眼清楚，再试按键。接收时主呼号切换为对方呼号，发话时使用暖橙色提示。

A · 音量减 / 中继
短按减小音量；长按进入中继列表。
其他页面长按 A 返回首页。
B · 发话 / 确认
首页短按开始，再按停止；长按强制停止。
菜单中短按确认。
C · 音量加 / 菜单
短按增大音量；长按打开菜单。
列表中 A / C 选择上一项、下一项。
