# FMO 0.7.32 · 互信优先与自动添加

M5 FIRE 类与小智 Xingzhi Cube 1.54 TFT 分别构建，不可混刷。

- 已明确确认、未过期且适用于当前证书根的服务器自动加入本体系中继列表，并排在前面。
- 自动加入不切换当前服务器，不制造“本机已验证”记录；实际认证成功才记录接入验证。重复刷新不重复添加或反复写入。
- 网页恢复“发现 → 添加 → 从已保存中继选择”的流程，保留高级手动添加。
- 手动删除的中继不会被自动刷新加回；主动手动添加可以恢复。指纹冲突不会自动覆盖原记录。
- 小智与 M5 的中央呼号改为清晰的红发绿收闪烁，发射时顶部自己的呼号同步闪烁；关闭提示时仍保留方向颜色。
- TES 专用 #1845 只自动加入 TES 体系，不标为 BH1JSS 互信。
- 保留 0.7.31 的旋转、PTT 保持/按住、呼吸提示、根 CA 选择限制、小智电量等功能。

升级仅写 application.bin：M5 0x10000，小智 0x30000；保留 NVS、网络和证书。首次安装小智使用 manifest 中的 initial-settings.bin，会初始化不兼容的原厂设置区，需先备份。

互信记录绑定完整端点、指纹、适用客户端根与期限。服务器认证政策仍可能变化；“根 CA 已导入”“名称属于某集群”或“加入收藏”均不等于双方互信。服务器核对结果见 PEER_TRUST_AUDIT_0.7.32.md。
