# FMO 0.7.30 · M5 与小智

一套共用源码，按硬件分别构建。选择具体板型，不可混刷。现有已验证硬件：M5 FIRE 类原版 ESP32（模拟麦克风 GPIO34 / DAC GPIO25）；Xingzhi Cube 1.54 TFT WiFi（ESP32-S3 R8N16）。不代表其他 M5 或其他小智板型兼容。

## 功能

- 发现节点可直接选择并尝试接入，认证成功后记录验证状态；网页保留高级手动添加。
- 发话呼号红色、接收绿色呼吸提示；“显示与按键”菜单控制呼吸开关、每次 90° 屏幕翻转、PTT 保持或按住发话。设置断电保存。
- BG5ESN 根 CA 从网页与设备选择列表移除，禁止重新选择；不删除原证书/身份备份。
- 小智显示电量百分比、电池条和充电标记。按原板 ADC 基准估算，不能替代精密电量计。

## 升级与回退

已有本项目 FMO 固件请使用保留配置升级，只写对应板型的 application.bin：M5 为 0x10000；小智为 0x30000。不要擦除 NVS 或执行更换使用者。升级前按设备唯一标识确认硬件并保留备份。

首次安装要使用对应板型的全部文件及 manifest 地址。小智的 initial-settings.bin 为全 FF 初始化数据，仅用于首次安装：清空 0x9000–0x20FFF 新设置区，原小智配置不兼容；先完整备份原固件。首次安装需要重新配网和申请自己的设备证书。

网页使用桌面 Chrome/Edge 的 Web Serial，本地依赖打包，无运行时 CDN。下载 SHA256、芯片类型、现有分区和最终确认均在写入前检查。不同硬件选择会清除之前的硬件确认，首次安装另需确认。已有 FMO 升级只写应用；禁止整片擦除。

本包不含设备 NVS、私钥或证书。保留原 M5 0.7.29 与小智 0.7.29-s3.1 的本机备份；需恢复原厂小智时使用私人完整备份，不能使用另一台设备的备份。

## 验证范围

两板型独立构建、完整离线回归、按键/设置保存/发现选择/根 CA 限制测试。发布过程还会记录两台实机的写入校验、启动版本、联网与证书状态；真实显示和声音由现场反馈确认。线上刷写自动化模拟不等于浏览器真实 USB 写入验收。

芯片/地址/文件 SHA256 见同包 manifest.json 和 SHA256SUMS。源码及正式发布门禁见 GitHub 仓库 docs/RELEASE.md；对应提交的 host-tests 与两种硬件构建均通过后发布。
