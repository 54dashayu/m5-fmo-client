# 小智 0.7.78 稳定版 · M5 保持 0.7.77

仅更新小智 Xingzhi Cube 1.54 TFT WiFi（ESP32-S3）。M5 本次不更新；两种硬件从此可以独立发布和编号。

- SSTV 收图保存改为后台执行，界面显示“正在保存，请稍候”，等待时不再卡住界面。
- 保存任务结束前拦截重复按键，完成后清除残留按键状态，避免连续触发保存或页面操作。
- 保存成功后显示图片编号；保存未完成时保留当前图像供重试，不再统一误报“相册已满或存储忙”。

已知情况：用户在 0.7.78-save.1 测试中确认，首次保存仍可能显示“保存未完成，请稍后重试”，再次按保存可成功。本版改善反馈和重复操作处理，没有宣称消除首次保存失败；用户确认接受此情况并要求稳定发布。

验证：保存任务延迟与连续按键、失败和重试、残图保存、任务启动失败、接收和相册相关回归。测试版实机确认联网、音频及配置与 3 张原有图片保留；稳定版只调整版本标识，发布门禁和构建记录另见发布记录。

升级请选择“保留配置升级”，只使用与硬件匹配的固件。配置、证书、密钥及已保存图片保留。本版不包含已取消的其他 SSTV 制式识别开发。
