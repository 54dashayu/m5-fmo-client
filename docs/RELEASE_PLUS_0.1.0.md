# ESP32-2432S028R Plus 0.1.0

首个独立正式版本，基于用户验收的 dev5t6b 功能固定版本。仅适用于白色 ESP32-2432S028R Plus（ESP32-WROOM-32E，4MB Flash，ST7789，XPT2046）；并非 LCDWIKI E32R28T 或其他 CYD 通用包。部分商品图写作2432S0248R，须以实物丝印与接线核对。

## 功能

- 首页底部菜单、音量+、音量−、PTT；菜单、中继、相册直接点选，保留返回。
- PTT按住发话、松手或滑出停止，唤醒手势不触发；连接与频道忙门禁保留。
- MAX9814：OUT→IO35，VDD→3.3V，GND共地；菜单麦克风测试只测本地电平。用户已确认电平随说话变化。
- Wi-Fi、设备管理网页、多CA身份；内部Flash相册与真实容量提示，TF不启用。
- 恒亮/关闭背光，避免此前PWM相关杂音；保留SSTV编解码与图片链路。

## 已知限制与验收范围

PCM/实际通联播放仍可能有噼啪声，本版不宣称音质问题已解决。PTT真实通联与SSTV端到端收发未完成本板实物验收。相册容量有限且无OTA，请使用网页显示的实际剩余空间。硬件扬声器测试正常不代表PCM播放已经正常。

本地回归包含触摸校准、坐标、直接点选、PTT释放/滑出/唤醒/读取失败、内部相册容量与保存失败、校准边界。dev5t6b板上音频就绪，麦克风约8kHz，用户确认输入电平变化。正式版仅固定版本，不包含新的音频算法修复。

## 安装与数据保留

已有本项目Plus分区布局请选择保留配置升级，仅写0x10000应用区，保留配置、证书、校准和内部相册。不兼容分区拒绝升级。首次安装需先备份原有数据并确认，将写引导、分区、新设置区和应用；不会整片擦除，不包含任何设备私钥或个人证书。

Plus专用分区：NVS 0x9000/0x6000、PHY 0xf000/0x1000、应用0x10000/0x310000、内部相册0x320000/0xe0000，终点0x400000。
线上M5、小智0.7.79保持不变，本次仅发布Plus。
