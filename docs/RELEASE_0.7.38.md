# FMO 0.7.38 · 自动证书体系选择与双设备更新

提供 M5 FIRE 类（ESP32）与小智 Xingzhi Cube 1.54 TFT WiFi（ESP32-S3 R8N16）两套独立固件，请按具体硬件选择，不可交叉刷写。

## 本次更新

- 网页“本机设备证书”增加自动体系选择：逐项勾选、全选可用体系、全不选和保存。仅具备同呼号、有效且匹配本机密钥的设备证书才可选择；只有根 CA 不等于已取得设备身份。
- 主动接入服务器时，根据新鲜、已验签且确认互信的体系资料匹配身份。当前身份可接入则优先保留，否则从勾选范围中选择有效身份，重启并恢复所选服务器；后台发现不会自行切换身份。
- 未勾选的其他身份不会自动启用；已确认的体系没有可用身份时保留原连接并提示。缺少有效体系资料时保持当前身份尝试接入，不按名称猜测 CA。
- 默认关闭自动切换，“全不选”保存后恢复手动方式。设置与证书持久保存；中断恢复校验目标身份和服务器。

- 小智本机显示、网页状态与语音报文的自动呼号前缀统一改为 `E.`；M5 仍为 `M.`。裸呼号、证书、密钥和 UID 不改变，无需重新申请证书。
- 小智网页登录前即可显示“ESP32/小智设备管理”，同时修正登录提示、硬件名称及按键操作说明；M5 保留自己的标题。

- 新增 ABC 三键功能组的全部六种排列，保存后生效、重启保留。主页底栏固定按实体 A、B、C 排列，文字、PTT 开始/停止提示和收发颜色跟随当前分配。
- “按键分配方案”选择页固定实体 A 上选、B 保存、C 下选，长按 A 返回；其他页面提示跟随已保存方案。仅浏览候选方案不会应用。
- 保留连续 300 秒无收发、无按键时背光降至 3%，收发或按键后恢复至 100%；不提供单独的“屏幕休眠”菜单。
- 小智构建支持 JSON 板型配置：ST7789 SPI 屏幕尺寸、颜色、偏移、背光及现有外设引脚；校验引脚冲突和保留引脚。自定义配置使用独立构建目录。
- 保留互信优先发现、证书体系、屏幕旋转、PTT 模式、电量，以及 M5 灯条/呼号闪烁互斥、小智红发绿收提示。

## 验证范围与限制

- 小智已刷入 0.7.38，USB 与实机网页验证勾选/全选、禁止未勾选身份、保持兼容身份，以及 TES → BH1JSS 接入 RF Link #3191、BH1JSS → TES 接入 AI Passport #1845。两条连接均回读在线且音频就绪；测试后恢复原 TES #1791、按键方案和自动切换关闭状态。该测试确认认证和连接，不代替新版本双向语音听感验收。
- 小智按键与底栏已在 0.7.36 由用户验收，E. 前缀已在 0.7.37 获用户确认；此前两台已完成双向语音实测。
- M5 0.7.38 完成编译与共用逻辑回归，本轮未刷入验收新增按键和自动体系功能；上一实机确认版本为 0.7.33。
- 自定义 240×320 配置已编译验证，但未在对应实物屏幕验收。当前只接入 ST7789 SPI 驱动，其他控制器需开发驱动；2.8 英寸设备不能仅凭尺寸或同为 S3 直接刷入本固件。
- 小智独立电源键行为未改变，短按息屏/长按关机尚未实现。缺少该按键的实际接线资料，不能保证可由固件控制。

## 升级与回退

已有 FMO 设备选择“保留配置升级”，只写应用区，保留网络、证书、密钥及按键设置。原厂设备首次安装请先整机备份。公开固件与 ZIP 不含设备身份、私钥或实际 NVS 数据。

两个硬件均保留 v0.7.33 历史 Release；原在线 v0.7.32 目录也保留。回退请选择相同硬件的应用区固件，必要时恢复自己设备的私有备份。
