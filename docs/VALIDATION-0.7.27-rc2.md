## 申请体系选择界面

同日增加 BH1JSS / BI4TES 申请切换按钮及所有已保存根的下拉选项。申请表与正在使用的身份独立；无在线适配的体系只显示原方申请和手动导入说明，实际硬件类型固定 M5。浏览器三模式可见性测试、JS 语法检查、固件构建及全套离线回归通过。此 UI 改动未修改任何签发端规则；BH1JSS 现有 UID 校验仍为必填，改为选填需同步服务端。
