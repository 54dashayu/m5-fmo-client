## 升级

在线刷机页选择自己的型号及“保留配置升级”。仍仅支持 16MB Flash 的 M5GO / FIRE 类 ESP32 和小智 Xingzhi Cube 1.54 TFT ESP32-S3 R8N16。

出现“相册未就绪”的 M5 用户：升级后退出 SSTV 接收，进入网页“SSTV相册”。如提示旧数据无法识别，确认不需保留后再点击“初始化相册”；初始化成功后重新进入接收，并从头播放 Robot36。

不会自动格式化已有相册。原 0.7.60 / 0.7.63 下载目录继续保留。
