# 0.7.28-dev：无设备证书时选择体系

本地开发版；未发布正式版或在线刷写默认版本。

网页和 M5 的根 CA 列表均允许选择只有根证书的体系。确认后保留旧身份库，暂停通联并重启到所选体系；不使用原体系证书冒充新体系接入。未取得证书时显示待申请/领取，网页提供该体系申请或导入入口；M5 在当前无证书体系按 B 进入网页管理。

领取任务继续独立处理。切入待领取体系使用该任务原来绑定的密钥；无任务时使用已保存的该体系密钥或保留当前本机密钥。返回证书通过校验后保存，显示待启用，由用户确认启用后重新登录。旧体系可随时选择切回。

无证书切换使用 empty_next 持久事务，保存目标 seed bank 后提交标志，重启时替换活动密钥、清除活动证书引用、设置 selected_ca，并保留所有设备证书银行和领取任务。未完成事务时不加载旧证书进行新体系登录，管理服务仍可恢复。更换使用者清除上述选择和事务键。

验证：完整离线回归和 ESP-IDF 构建通过；新增空体系切换原身份保留、申请密钥一致、7 个写入失败点重试恢复；更新实体 UI 按键逻辑主机测试及根列表状态测试。浏览器 mock 验证无证书切换请求、待领取标记、对应 BI4TES 表单入口。已重新生成中文字库。

2026-11-12 实机验证：核对新 M5 MAC 8c:aa:b5:80:2a:e0（192.168.31.126），仅刷写 0x10000 应用区并校验成功，没有擦除 NVS。网页读回 0.7.28-dev，本机公钥与升级前一致。初次显示 BH1JSS 已接入、BI4TES 等待校时领取；选择 BI4TES 并确认后设备重启，浏览器自动恢复登录。随后读回 BI4TES 设备证书已就绪、正在使用且当前中继已接入；BH1JSS 设备证书已保存可切回，五个根体系保留。BI4TES 在此期间自动领取完成，未重新提交申请。因领取和切换时间接近，本次不单独断言无证书状态持续跨重启已实测；该路径已有离线故障恢复测试。实体按键和屏幕显示仍待用户验收。
