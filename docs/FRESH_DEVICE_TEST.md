# 新设备从零申请验证（0.7.27-rc1）

本测试构建仅带公共根信息：BH1JSS M5、BI4TES / FMO Passport、QFM-FMO Gateway。镜像不包含设备证书、私钥、呼号和 Wi-Fi 凭据。首次开机在设备生成独立密钥；已有设备只升级固件不会自动删除原身份，本次新测试设备先单独清空 Flash。

1. 连接设备屏幕显示的热点，打开 192.168.4.1，用该设备八位管理码登录并配网。
2. 本机设备证书页确认三个根体系均未安装设备证书。
3. 申请页选择 BH1JSS 或 BI4TES，填写本机使用者呼号及签发方所需资料。BI4TES 材料直接提交原方审核服务。
4. 待领取请求保存在本机，联网、空闲且内存足够时自动查询。断电重启后继续领取；只有原方已签发且证书链、公钥、呼号、UID 和有效期校验通过才安装。主动切换身份或取消会停止旧的待领取请求。
5. 新设备证书不能用另一台设备的普通证书包替代。QFM 尚无已确认的自动申请适配，仅支持由原签发方审核后提供匹配本机密钥的完整证书包。
6. 已安装多个体系后分别选择中继；来回切换应自动重启、恢复该体系列表和验证状态，并刷新发现候选。

正式默认刷写页保留 0.7.26。rc1 在 GitHub 主机测试与固件构建通过后部署到独立 testing/ 入口；不创建预发布 Release。待新设备申请验证后再准备 0.7.27 正式发布。
