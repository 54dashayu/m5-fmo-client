# M5 / 小智 0.7.68：自动连接已保存的 Wi-Fi

保存多个 Wi-Fi 后，开机先尝试原先选中的网络；约 22 秒未能连接，就轮流尝试其他已保存网络。连接成功后保持连接，断线时自动重试。不会自动删除网络或修改密码。

- 保留最多 6 个 Wi-Fi、证书、按键设置及 SSTV 相册。
- 手动配网和扫描优先，自动重连不会抢占正在进行的操作。
- 小智已实测：首选网络不可用时，自动连上另一保存网络并接入 FMO。
- 两板编译与离线回归通过。

打开 [在线刷写页](https://app.bh1jss.net/m5-flasher/)，选择对应设备。已安装本项目固件的用户请选择“保留配置升级”。

回退版本：[M5 / 小智 0.7.67](https://github.com/54dashayu/m5-fmo-client/releases/tag/v0.7.67)。
