# 更换使用者与证书导入

## 当前状态

公开稳定固件仍为 0.7.14。0.7.16-dev 本地候选版新增“本机设备证书 → 更换使用者”，已刷入当前连接的 M5 进行验证，未作为公开稳定版发布。在线刷写页面明确说明升级和首次安装均不主动清空已有身份。

## 新版使用流程

1. 使用屏幕管理码登录 M5 自己的网页后台。
2. 在“本机设备证书”展开“更换使用者”，填写新呼号并两次确认。
3. 设备生成新随机密钥，重启时清除旧证书、证书备份和待领取申请，保留 Wi-Fi、中继列表。
4. 重新输入管理码，以新呼号提交在线申请；也可下载本机签名申请文件，连同照片和已有 FMO UID 交给管理员核实。
5. 自动领取，或导入管理员后台下载的完整设备证书包。

私钥留在 M5。证书包必须与当前公钥及呼号匹配。旧证书不会在服务器自动撤销，应联系签发管理员处理。不要用旧设备 NVS 镜像批量克隆新设备。
