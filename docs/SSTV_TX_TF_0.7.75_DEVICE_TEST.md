## 升级

设备为 M5 FIRE 类 ESP32-D0WDQ6-V3，串口 `/dev/cu.usbserial-02012E7E`。开始时实际版本为 0.7.74，因此将 0.7.74 的格网定位、资料管理与 APRS 设置改进合入原 SSTV 开发版，标记 0.7.75-dev。没有刷写旁边的小智。

先读取并核对分区表、保存原 0.7.74 应用区以供回退。未读取或保存 NVS 私钥。只执行应用区写入：

```text
esptool --chip esp32 --port /dev/cu.usbserial-02012E7E --baud 460800 write_flash 0x10000 build-m5-regression/m5-fmo-ui-preview.bin
```

程序 2,950,560 字节；擦写范围 `0x10000–0x2e0fff`；esptool 报告 `Hash of data verified`。没有写分区表、NVS、`spiffs` 或 `sstv` 分区。

重启后版本为 0.7.75-dev，呼号、公钥、证书存在状态与已保存 Wi-Fi 均与升级前一致；联网、音频初始化和 1791 中继认证成功。升级前内部相册为 0 张，升级后仍为 0 张，不能把此结果宣称为“已有非空相册实测”。
