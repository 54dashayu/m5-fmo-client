# M5 / 小智共用功能候选 0.7.30-dev.1

## 两种固件的关系

维护位置为 xingzhi-fmo-adaptation，共用证书/根 CA、身份、发现与中继、通联协议、音频编解码、网页、菜单和按键逻辑。板型在编译时选择，分别生成 M5 FIRE（ESP32，原生 ADC/DAC、320×240、GPIO15 灯条）与 Xingzhi Cube 1.54 WiFi（ESP32-S3 R8N16，标准 I2S、240×240、无灯条）固件。两种二进制不可互刷；不代表其他 M5 Core 型号已经适配。

## 此版本功能

1. 设备发现列表允许选择尚未接入验证的新鲜、签名验证过的候选。选中后保存并连接，只有实际认证成功才有接入成功记录。列表变动、过期资料、身份变化及通联中切换仍有检查。网页本机发现列表和全量广播目录改为直接“接入”；保留高级手动添加入口及已有中继删除/重命名功能。
2. 通联大呼号：发话时本机呼号为红色，接收时对方呼号为绿色，使用明暗呼吸变化，不完全消失。菜单“显示与按键 → 呼吸灯”控制屏幕呼吸变化及 M5 实体灯；关闭后呼号仍用红/绿固定颜色区分状态。小智不驱动不存在的灯条 GPIO。
3. “显示与按键 → 屏幕翻转”：每次 B 确认增加 90°，0/90/180/270 循环。按键 A/B/C 仍对应原物理键，不随屏幕重映射。M5 竖屏使用 240 宽紧凑布局；小智保持方屏布局。
4. “显示与按键 → PTT 保持”：开启为原有短按开始、再按停止；关闭为按住 B 发话、松开停止。仅主页使用 PTT，其他菜单 B 仍用于确认。组合键取消、开机按住防误发、长按菜单隔离及发话时限沿用。改变模式会停止发话。
5. 按 BG5ESN 根公钥识别，从网页与设备根 CA 列表隐藏，停止新设备预置，禁止重新导入/选择。不按槽位删除，不清除已有根/设备证书/密钥备份，BH1JSS、BI4TES 与其他根体系不受影响。

6. 补齐小智电量显示：顶部电量百分比、电池条及充电“+”标记。按原板 ADC2 CH6 / GPIO17、12 位、12dB 采样及 GPIO38 高电平充电检测，三次采样平滑；连续读取失败显示未知，避免伪装为 0%。满电时与原板一致不显示充电标记。ADC 原始值 1970–2430 估算为 0–100%，不是精密电量计。

电源配置来源：[原板 PowerManager](https://github.com/geek-alpha/xiaozhi-esp32-music/blob/f5352ac5a6bf921299c555f84e02cdb242d276f9/main/boards/xingzhi-cube-1.54tft-wifi/power_manager.h) 及同目录板级构造函数。引脚、衰减及电量基准只用于此确切板型。

## 设置保存

方向、呼吸开关及 PTT 模式作为一个值存于独立 fmo_ui NVS 命名空间。默认方向 0°、呼吸开启、PTT 保持开启。重启恢复设置，保存失败时显示错误并保持当前模式。未修改身份、Wi-Fi 或原中继存储布局。

## 构建和验证

ESP-IDF 5.5.1 环境：`python tools/build_board.py m5` / `python tools/build_board.py xingzhi`。
离线回归：设置 IDF_PATH 后使用带项目 requirements 的 Python 运行 `python tools/run_tests.py`。
新增测试覆盖直接选择未验证候选、不错误标为已验证、失效列表/过期/身份/忙状态拒绝；PTT 按下与释放、组合键、菜单和模式切换；设置 16 种组合恢复及写入失败；BG5ESN 公钥禁止导入及列表隐藏。网页 JavaScript 语法检查通过。

打包：提交源码后运行 `python tools/package_board_candidate.py m5` / `python tools/package_board_candidate.py xingzhi`。每个候选包包含芯片/版本/源码提交/地址/校验和 manifest。没有发布、没有刷新在线刷写页面。

## 真机待验收

本版本尚未刷入。此前 0.7.29-s3.1 的双向音频验收不能算作本版本通过。分别检查：

- 电池供电/USB供电两种状态的电量与充电标记；Wi-Fi通联期间采样不影响音频。
- 四方向文字、颜色、裁切、按钮与菜单滚动；重启后方向保存。
- PTT 保持/按住模式的双向音频与松开停止；断线/菜单/组合键不误发。
- 红发绿收，呼吸关闭后实体灯熄灭且呼号保留静态颜色；重启保持设置。
- 未验证节点直接选择，接入失败有状态提示、成功后记录验证；网页高级手动添加仍可用。
- BG5ESN 不出现在两个根 CA 选择界面，其他体系及现有证书不变。

升级前保留当前配置备份并确认设备唯一标识。小智在当前 FMO 布局下可只更新 0x30000 应用；原版 M5 对应 0x10000。旧原厂小智固件不是此布局，首次安装必须采用此前的完整备份与分区流程。不要擦除 NVS。回退用对应板型原候选，原厂小智完整备份仍为私人本地文件。
