# FMO 0.7.36 · 可配置按键与板型配置

提供 M5 FIRE 类（ESP32）与小智 Xingzhi Cube 1.54 TFT WiFi（ESP32-S3 R8N16）两套独立固件，请按具体硬件选择，不可交叉刷写。

## 本次更新

- 新增 ABC 三键功能组的全部六种排列，保存后生效、重启保留。主页底栏固定按实体 A、B、C 排列，文字、PTT 开始/停止提示和收发颜色跟随当前分配。
- “按键分配方案”选择页固定实体 A 上选、B 保存、C 下选，长按 A 返回；其他页面提示跟随已保存方案。仅浏览候选方案不会应用。
- 保留连续 300 秒无收发、无按键时背光降至 3%，收发或按键后恢复至 100%；不提供单独的“屏幕休眠”菜单。
- 小智构建支持 JSON 板型配置：ST7789 SPI 屏幕尺寸、颜色、偏移、背光及现有外设引脚；校验引脚冲突和保留引脚。自定义配置使用独立构建目录。
- 保留互信优先发现、证书体系、屏幕旋转、PTT 模式、电量，以及 M5 灯条/呼号闪烁互斥、小智红发绿收提示。

## 验证范围与限制

- 小智 1.54 英寸实机已刷入 0.7.36，用户确认按键分配、底栏提示和菜单调整正常；USB 回读联网、证书有效、服务器连接和音频模块就绪。原有双向音频已在此前版本实测。
- M5 0.7.36 已完成编译和共用逻辑回归；本轮未刷入 M5 验收新增按键方案。M5 上一次实机确认版本为 0.7.33，可从历史 Release 回退。
- 自定义 240×320 配置已编译验证，但未在对应实物屏幕验收。当前只接入 ST7789 SPI 驱动，其他控制器需开发驱动；2.8 英寸设备不能仅凭尺寸或同为 S3 直接刷入本固件。
- 小智独立电源键行为未改变，短按息屏/长按关机尚未实现。缺少该按键的实际接线资料，不能保证可由固件控制。

## 升级与回退

已有 FMO 设备选择“保留配置升级”，只写应用区，保留网络、证书、密钥及按键设置。原厂设备首次安装请先整机备份。公开固件与 ZIP 不含设备身份、私钥或实际 NVS 数据。

两个硬件均保留 v0.7.33 历史 Release；原在线 v0.7.32 目录也保留。回退请选择相同硬件的应用区固件，必要时恢复自己设备的私有备份。
