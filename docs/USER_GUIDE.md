# 配网、日常使用和排障

## 网页管理

首次启动未联网时，连接屏幕上的 M5 热点并访问 <http://192.168.4.1>。热点密码和网页登录码均为屏幕显示的 8 位数字，每台设备首次随机生成并保存，重启和保留配置升级不变；更换使用者后重新生成。

已联网设备：长按 C → “网页管理”，查看局域网地址；手机 / 电脑与设备在同一 Wi‑Fi 下直接访问该地址。在网页管理页面停留时可开启设备热点；退出后，已连接家庭 Wi‑Fi 的设备会回到正常工作模式。

网络设置支持搜索 2.4 GHz 网络、信号强度显示、密码显隐、保存 / 删除 / 重连，最多保存 6 个网络。保存多个网络不等于承诺自动无缝漫游；需要时在列表选择连接。

## 通联

1. 等待“守听中”，确认中继正确。
2. 短按 B 后松手，看到发话状态再说话。
3. 再短按 B 停止；长按 B 可强制结束。
4. 用另一台同中继设备确认声音，不要只用本机发送计数判断已收到。

主页 A / C 短按调整音量，长按 A 进入中继列表，长按 C 打开菜单。列表用 A / C 选择、B 确认；非主页长按 A 返回主页。菜单还包含音量、身份、网页管理、扬声器测试和麦克风测试。两项音频测试不向服务器发话。

中继可在设备网页增加，需要名称、呼号、UID、地址、端口和准确的服务器证书指纹；不要随意填写指纹。最多保存 4 个。网络可达、证书有效、服务器信任和语音可播放是四个不同条件。

## USB 备用管理（macOS / Linux）

网页优先。设备 Wi‑Fi 尚不可用时，在仓库根目录安装 `requirements.txt` 后运行：

```sh
python tools/usb_admin.py --serial /dev/cu.usbserial-实际端口
```

打开 <http://127.0.0.1:8772>。服务只监听本机；不要转发到公网。此辅助工具使用 POSIX 串口接口，本版未验证 Windows USB 管理。退出工具后再刷机。

## 常见问题

| 现象 | 检查顺序 |
| --- | --- |
| 找不到热点 | 长按 C 进入网页管理；查看屏幕上的实际 SSID，重启后密码会变化 |
| 连上 Wi‑Fi 但未接入 | 校时是否完成、设备证书是否有效、中继是否信任对应根、目标指纹是否正确 |
| 下载了根证书仍无法登录 | 根证书供服务器管理员使用；用户需要与本机公钥匹配的设备证书 |
| 导入别人的证书失败 | 属于预期行为，证书绑定设备公钥，不能跨设备复制身份 |
| 网络繁忙 / 断续 | 查看信号和发送丢弃计数；比较同一握持方式下的路由器与手机 2.4 GHz 热点 |
| 音调异常 / 音频初始化失败 | 核对模拟音频引脚和板型；本版仅验证上述 FIRE 类硬件，不要强行改采样率掩盖硬件不匹配 |
| 黑屏 / 反复重启 | 查看供电、USB 线和重启诊断；不要把所有复位都判断为证书问题 |
| 字太细 / 颜色反转 | 使用仓库完整配置和字库，当前屏幕配置启用了反色修正 |

`txPackets` 是提交 MQTT 发送队列的数量；`txRetries` 是软件提交忙后的重试次数，不是无线重传次数。`txDropped` 包含本地过期、溢出、取消旧发话等丢弃；`txPending` 是待提交数量。已提交给 TCP 的数据无法由本地缓冲撤回。

目前没有对所有路由器、长时间通联、所有 FMO / Passport 版本或其他 M5 板型作兼容保证。网络弱时仍可能出现断续或重连。

## 0.7.22 管理与发现

登录时勾选“记住此浏览器”，同一浏览器、同一访问地址可在设备重启后继续登录；退出或更换使用者会撤销授权。管理码随机生成，不是所有设备共用一个，亦不保证全球绝对唯一。

已确认适用于当前证书体系的服务器自动加入中继列表并优先显示，不自动切换当前服务器。网页发现节点恢复“添加 → 在中继列表选择接入”；高级手动添加保留。手动删除会阻止自动加回，主动手动添加可恢复。TES 的 #1845 只对 TES 体系自动加入；其他身份不能继承其接入证明。呼吸提示开启时，中央呼号红发绿收闪烁，发射时顶部自己的呼号同步；关闭后保留红绿方向颜色但停止闪烁。
