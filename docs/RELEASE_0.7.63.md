# FMO 双板固件：M5 0.7.60 / 小智 0.7.63

本次按板型独立发布：M5GO / FIRE 类 ESP32（16MB Flash）使用 0.7.60，小智 Xingzhi Cube 1.54 TFT ESP32-S3 R8N16 使用 0.7.63。版本号不同，请按硬件下载。

## 新增功能

- Robot36 SSTV 接收菜单、实时预览、手动保存，保存成功后自动等待下一张，随时退出。
- 音频中断后可在通联结束时手动保存已有图像；相册记录有效行数。
- 设备与网页 SSTV 相册，三列缩略图、大图查看、原图或带框导出；接收时间、服务器/中继与自定义相框内容。
- 浏览器缓存图片并直接上传照片墙，可选择原图或带框；不需要跳转重填信息。
- 显示 CPU、运行内存、扩展内存与照片空间，提示可用容量及及时清理。
- 小智 0.7.63 修正屏幕传输缓冲和调度等待，改善呼号及 SSTV 实时显示；开机网络状态单行显示。
- 保留语音通联、证书体系、配网、中继、按键方案和屏幕设置。

## 验证

M5 已完成接收和保存实机测试。小智 0.7.63 的呼号和 SSTV 实时显示由用户确认正常。本次正式构建移除测试后缀，不再改动固件功能，不重新刷写用户设备。

## 刷写与升级

仅适配 16MB Flash 的上述硬件，M5 无需 PSRAM。Core2/CoreS3、4MB M5 和其他接线设备不适用。刷机页会核对芯片及 Flash 容量。

已有本项目固件选择“保留配置升级”。相册分区已经存在时只写应用；旧版标准分区可在保留 NVS、证书、Wi-Fi 和原数据区位置的情况下新增相册分区。旧布局 M5 同时更新引导程序，以识别完整 Flash 容量。非标准分区会拒绝升级。首次安装小智会初始化新布局设置区，请先自行备份。

公开包不含设备私钥、证书或 NVS 备份。相册最多 20 张，实际数量取决于图片大小及剩余空间，建议及时导出和清理。

历史 0.7.38 保留下载。回退请选择同一板型固件并保留当前分区表；不要覆盖为旧分区表或用首次安装清空设置。
