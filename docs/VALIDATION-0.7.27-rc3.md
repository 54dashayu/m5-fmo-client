# 0.7.27-rc3 独立证书领取验证

2026-11-12，本地测试固件，未发布到 GitHub Release 或在线刷写页。

## 行为

- BH1JSS、BI4TES 分别保存领取任务、申请时密钥和状态；私钥只留在 NVS，请求仅发送签名后的公开申请字段。
- 切换当前登录体系不停止另一体系领取。后台空闲轮询，重启恢复任务。
- 返回证书验证签名、根、公钥、呼号、UID、有效期后存入对应身份库，不切换当前身份、不重启、不改变中继。
- 取消只影响所选体系；更换使用者清除两套任务。
- 旧请求迁移失败时保留记录并延后身份切换，管理服务仍可启动。
- 同体系已有不同密钥身份时保留原身份并报冲突，不覆盖。
