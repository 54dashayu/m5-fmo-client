# 0.7.70-dev 本机身份管理

适用：M5 / 小智共用网页与设置接口。本地候选构建，未修改在线刷写页或 GitHub。

- “本机设备证书”改为“本机身份管理”，页面顶部提供本机呼号。
- 未绑定身份时保存裸呼号，自动填入证书申请；已有当前/备用证书或领取申请时禁止直接改号，使用原有更换使用者流程。
- M5 的 M.、小智的 E. 前缀可以关闭，作用于硬件主页、网页状态和语音包呼号；认证用户名、证书呼号及 UID 不变。
- APRS SSID 0–15 单独保存，不混入证书呼号或语音呼号。
- 保存经纬度、设备、通联频率、天线、高度与备注。经纬度可成对清空，(0,0) 是有效位置；频率单位 MHz，高度为整数米。
- 参考配置页的设备/天线 15 字节、备注 63 字节限制，严格校验 UTF-8、控制符和逗号；所有校验失败都不写入设置。
- 设置写入单独 NVS 记录，默认沿用原有设备前缀，无位置资料。升级不清除证书或相册；更换使用者时清除旧站点资料。

新增可选 APRS-IS/FMO BEACON 广播，默认关闭。保存位置与频率、填写 APRS 登录码并明确开启后，空闲时每 10 分钟发送；语音及 SSTV 接收期间暂停。报文携带当前有效设备证书和签名；APRS 呼号不含 M./E.，SSID 0 不附加 -0。备注仅本地保存。状态只确认交给服务器，不代表已在公开地图显示。SSTV 编码与发射未实施。

完整身份恢复：明确区分 Wi-Fi 证书安装和 USB 含密钥备份恢复，添加本机 USB 管理入口说明；保留原始错误，避免提交时被笼统错误覆盖。

参考：用户设备 http://192.168.31.146/config.html 及 configService.js；https://bg5esn.com/docs/fmo-formate/ 约定 APRS SSID 不属于证书身份字段。

验证：两板编译；设置参数边界、JSON 往返；真实 API 的认证/证书锁定/忙碌保护/提交失败/读回；前端实际事件处理、无效坐标不发送、失败保留草稿；身份切换 37 个存储故障点；浏览器演示表单保存与前缀预览。

新增离线验证：独立 CBOR/Ed25519 校验 BEACON 的证书哈希和签名，16 组可选字段/SSID 组合，极值坐标舍入；本机模拟 APRS 服务验证分段响应、验证登录、拒绝未验证或不匹配账号。未发送真实公网广播。
