# FMO 0.7.33 · 收发提示互斥修正

- M5 的“显示与按键 → 收发提示”在“呼吸灯”和“呼号闪烁”之间切换，二者互斥。
- 无灯条的小智固定使用呼号闪烁，不再被旧的呼吸灯设置关闭。
- 呼号使用每 400 毫秒显示/隐藏的明确闪烁；发话红色、接收绿色，发话时顶部自己的呼号同步闪烁。状态文字保持可读，通联结束恢复显示。
- 保留原有旋转、PTT、网络、证书和中继选择；沿用原设置存储位，不改写设备身份。

两台设备已升级，用户确认字体闪烁与灯条互斥正常。已安装设备只写应用区，回退可用 0.7.32 应用和私有备份。

独立电源键仍保持原硬件行为；本机实测短按关机，短按息屏尚未实现，不能将它宣传为此版本功能。公开原理图未提供独立电源键的普通 GPIO 输入，需要进一步核对硬件板本。
