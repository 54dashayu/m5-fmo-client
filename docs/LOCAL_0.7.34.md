# 0.7.34 本地开发：按键方案、息屏与板型配置

本轮不推送 GitHub、不创建公开 Release、不修改在线刷写入口。

## 按键分配

实体键默认位于屏幕上方，正面朝向用户时左 A、中 B、右 C；屏幕旋转不会改变实体键的名称。

设备菜单新增“按键分配方案”，可选择三个功能组的全部六种排列：

| 方案 | 实体 A | 实体 B | 实体 C |
| --- | --- | --- | --- |
| 1（默认） | 减小／上选／返回 | PTT／确认 | 增大／下选／菜单 |
| 2 | 减小／上选／返回 | 增大／下选／菜单 | PTT／确认 |
| 3 | PTT／确认 | 减小／上选／返回 | 增大／下选／菜单 |
| 4 | PTT／确认 | 增大／下选／菜单 | 减小／上选／返回 |
| 5 | 增大／下选／菜单 | 减小／上选／返回 | PTT／确认 |
| 6 | 增大／下选／菜单 | PTT／确认 | 减小／上选／返回 |

选择方案的页面始终使用实体 A 上选、B 保存、C 下选，长按实体 A 返回，不跟随候选方案变化。保存之后才生效，操作提示更新，重启保留。不会改变芯片硬件 BOOT 键或刷机按键。

## 屏幕休眠

菜单新增“屏幕休眠”：仅关闭背光，Wi-Fi、接收和音频保持运行。呼入或任意 ABC 按键唤醒。用于唤醒的首次按键不会发话、改音量或选择菜单，松开之后的再次操作才正常执行。

独立电源键的“短按息屏、长按关机、关机时短按开机”尚未实现。当前板型没有已确认可读的电源键 GPIO；公开图中独立开关连接电源管理/EN。不能把 GPIO21 电源保持输出误当按键输入。用户目前无法取得接线资料，因此本版保留独立电源键现有行为，不尝试猜测 GPIO。若后续取得实物走线或电路证据，再判断能否接入按键驱动或是否必须修改硬件。

## 可配置板型

共用功能代码，构建时选择 JSON 板型文件；运行时菜单负责旋转、收发提示、PTT 和按键分配。

默认配置：`boards/xingzhi-cube-1.54tft-wifi.json`。可配置屏幕型号标签、ST7789 分辨率、SPI 参数、颜色/镜像/偏移、背光极性，以及现有 I2S 音频、ABC 按键、电池、电源保持的 GPIO。生成头文件只放在构建目录，配置带哈希，USB 状态可回读型号与分辨率。

```
python tools/build_board.py xingzhi
python tools/build_board.py xingzhi --profile /absolute/path/my-board.json
```

自定义配置单独进入 `build-profile-<hash>`，不会覆盖已验收的默认板型产物。原始 ESP32 M5 不接受 S3 配置。保留既有 N16R8 分区要求，并校验引脚冲突、USB/存储引脚占用和显示内存边界。

当前实际接入的屏幕驱动只有 ST7789 SPI，支持 240×240、240×320 及其横向配置；其他驱动明确报错，不能只改型号名称假装兼容。ILI9341、ST7796、RGB 屏、触摸和其他音频 Codec 仍需新增并验证驱动。2.8 英寸只是尺寸，需先拿到具体控制器、分辨率及接线，尚无该设备的已验收配置。

当前 1.54 英寸硬件是唯一已实测的小智板型；自定义尺寸编译通过不代表目标硬件已通过实机验收。
