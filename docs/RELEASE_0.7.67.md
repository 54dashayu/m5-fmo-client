# M5 / 小智 0.7.67：相册管理改进

两款固件统一版本号为 0.7.67。

- 相册每张缩略图外增加勾选和删除按钮，不用先打开大图。
- 支持全选、删除所选；删除前确认，遇到失败停止并提示核对。
- 保留相册异常时的“初始化相册”按钮；全选删除不会初始化相册。
- 相册页面增加“照片墙”链接按钮，可直接打开 SSTV 照片墙。
- 保留语音通联、SSTV 接收、原图和相框上传等现有功能。

本地 M5 与小智均已刷入并完成实机测试，用户确认通过；升级后的配置和相册数据已校验保留。

打开 [在线刷写页](https://app.bh1jss.net/m5-flasher/)，选择自己的设备，已安装本项目固件的用户选“保留配置升级”。升级保留证书、Wi-Fi、按键设置及相册。

M5 如果提示“相册未就绪”，请按网页相册提示处理。初始化会清空相册区域；有旧图片需要保留时请先备份，不要直接初始化。初始化成功后退出并重新进入 SSTV 接收。

回退版本：[M5 0.7.66 / 小智 0.7.64](https://github.com/54dashayu/m5-fmo-client/releases/tag/v0.7.66)。
