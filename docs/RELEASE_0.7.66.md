# M5 0.7.66：改善语音卡顿

本次更新 M5 固件。小智继续使用 0.7.64，无需为本次更新重新刷写。

- 改善手台经 FMO 转来的语音卡断，支持每包超过 6 帧的音频。
- 优化长语音播放缓冲，减少网络到包不均匀时的中断。
- 保留原有 SSTV、相册、授权、配网和按键功能。

## 如何升级

打开 [在线刷写页](https://app.bh1jss.net/m5-flasher/)，选择 M5，使用“保留配置升级”，按页面提示连接并刷写。刷写期间保持 USB 连接。

已通过本地 M5 长语音和 SSTV 实机测试。欢迎用户在不同服务器和网络下测试；反馈时请附固件版本、语音来源及出现问题的场景。

## 验证范围

本地 0.7.66-audio-dev 实测通过，正式版仅去掉测试版后缀。一次记录完整解码和输出 32.88 秒手台语音，播放区间无缓冲耗尽；无音频包拒收、溢出、超时丢包、解码及输出错误。用户确认普通语音、SSTV 均正常。不同硬件与网络仍需更多用户验证。

接收包上限为 2048 字节，帧数按包长边界验证；M5 使用 480ms 有界缓冲，单一聚合包不会提前跳过缓冲，排队过期时限为 2 秒；接收环形缓冲仍为 5120 字节。小智公开固件文件保持不变。

升级保留已有配置与相册；本地刷写已核对分区表和数据区校验值。需回退时可使用 [0.7.64](https://github.com/54dashayu/m5-fmo-client/releases/tag/v0.7.64) 的 M5 固件包。
