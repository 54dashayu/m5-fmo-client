# SSTV 与 0.7.74 合并说明

合并基线：`v0.7.74`（`262db50dcb6053f863815aed88304b9f1828156d`）。合并开发版本：`0.7.75-dev.19`。本分支包含本轮 Robot36 发射、相册与 M5 TF 卡改动，并正式合入 0.7.74 的站点/网格定位、本机身份界面、发布说明和打包配置。以下为开发阶段历史记录。2026-11-16 用户最终确认 M5、小智收发正常、SSTV 验收通过，授权统一为 0.7.75 稳定版发布并同步 GitHub，取消测试入口；正式发布仍执行确切提交和标签双门禁。

## 板型差异

| 功能 | M5 | 小智 ESP32-S3 |
| --- | --- | --- |
| FMO 中继 Robot36 发射 | 支持 | 支持 |
| 网页裁剪、320×240 导入、上传进度和自动刷新 | 支持 | 支持 |
| 设备相册选图、发射确认 | 支持 | 支持 |
| 内部相册 | 支持 | 唯一存储介质，最多 20 张 |
| TF 卡选择、检测、格式化 | 支持 | 不显示入口，不注册对应 HTTP 路由；USB 操作返回不支持 |
| 三图横向预览 | 中间 120×90、两侧 80×60；固定 7200 字节缓冲及派生缓存 | 相同焦点/按键逻辑；复用 PSRAM 缓冲，窄屏裁切侧图外缘 |

小智构建不依赖 M5 的 FATFS/SDMMC 驱动；共享存储接口保留无硬件实现。网页按板型构建：小智没有 TF 卡管理 DOM，不发送卡状态请求；M5 单独嵌入 TF 控件片段。
