# SSTV 与 0.7.74 合并说明

合并基线：`v0.7.74`（`262db50dcb6053f863815aed88304b9f1828156d`）。合并开发版本：`0.7.75-dev.18`。本分支包含本轮 Robot36 发射、相册与 M5 TF 卡改动，并正式合入 0.7.74 的站点/网格定位、本机身份界面、发布说明和打包配置。公开稳定版仍为 0.7.74，此合并没有发布或覆盖原标签。

## 板型差异

| 功能 | M5 | 小智 ESP32-S3 |
| --- | --- | --- |
| FMO 中继 Robot36 发射 | 支持 | 支持 |
| 网页裁剪、320×240 导入、上传进度和自动刷新 | 支持 | 支持 |
| 设备相册选图、发射确认 | 支持 | 支持 |
| 内部相册 | 支持 | 唯一存储介质，最多 20 张 |
| TF 卡选择、检测、格式化 | 支持 | 不显示入口，不注册对应 HTTP 路由；USB 操作返回不支持 |
| 三图横向预览与小图缓存 | M5 内存受限路径，7200 字节像素缓冲 | 保持现有 PSRAM 显示路径 |

小智构建不依赖 M5 的 FATFS/SDMMC 驱动；共享存储接口保留无硬件实现。网页按板型构建：小智没有 TF 卡管理 DOM，不发送卡状态请求；M5 单独嵌入 TF 控件片段。

## 验证

- 两板固件构建通过，应用均适配现有分区。
- 完整离线回归通过，含 0.7.74 身份/站点/网格功能及 SSTV 编码、相册、卡任务、预览缓存和按键流程。
- 小智不支持 TF 时，卡操作拒绝且不改变存储选择/执行卡任务。
- 浏览器使用实际生成的小智页面和模拟接口：相册、裁剪上传、发射入口保留；无 TF 控件、无卡管理请求、无页面脚本错误。两板生成 HTML 的能力差异检查通过。
- 构建产物保存于父目录 `output/sstv-074-integration-dev18/`，附 SHA-256 和源码提交信息。这里的 `.bin` 为应用分区镜像，不是整片擦写包。

## 已知限制

M5 dev.17 的三图显示和缓存后切换由用户实机确认通过。此前 dev.16 多次发射接收结果不一致，最后一次记录为 `sstv_queue_dropped`、85%、393 帧提交、1 帧丢弃；不能宣称发射长期稳定。dev.18 未改动发送队列策略，本项仍待定位。本次只做源码合并、构建和模拟验证，没有刷入两台设备，也没有实际发射。小智本轮发射能力未做实机端到端验收。
