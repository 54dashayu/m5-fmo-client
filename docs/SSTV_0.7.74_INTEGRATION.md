# SSTV 与 0.7.74 合并说明

合并基线：`v0.7.74`（`262db50dcb6053f863815aed88304b9f1828156d`）。合并开发版本：`0.7.75-dev.19`。本分支包含本轮 Robot36 发射、相册与 M5 TF 卡改动，并正式合入 0.7.74 的站点/网格定位、本机身份界面、发布说明和打包配置。公开稳定版仍为 0.7.74，按用户要求仅提交在线刷写测试入口，不推送 GitHub、不覆盖原标签；不宣称通过 GitHub 正式版发布门禁。

## 板型差异

| 功能 | M5 | 小智 ESP32-S3 |
| --- | --- | --- |
| FMO 中继 Robot36 发射 | 支持 | 支持 |
| 网页裁剪、320×240 导入、上传进度和自动刷新 | 支持 | 支持 |
| 设备相册选图、发射确认 | 支持 | 支持 |
| 内部相册 | 支持 | 唯一存储介质，最多 20 张 |
| TF 卡选择、检测、格式化 | 支持 | 不显示入口，不注册对应 HTTP 路由；USB 操作返回不支持 |
| 三图横向预览 | 中间 120×90、两侧 80×60；固定 7200 字节缓冲及派生缓存 | 相同焦点/按键逻辑；复用 PSRAM 缓冲，窄屏裁切侧图外缘 |

小智构建不依赖 M5 的 FATFS/SDMMC 驱动；共享存储接口保留无硬件实现。网页按板型构建：小智没有 TF 卡管理 DOM，不发送卡状态请求；M5 单独嵌入 TF 控件片段。

## 验证

- 两板固件构建通过，应用均适配现有分区。
- 完整离线回归通过，含 0.7.74 身份/站点/网格功能及 SSTV 编码、相册、卡任务、预览缓存和按键流程。
- 小智不支持 TF 时，卡操作拒绝且不改变存储选择/执行卡任务。
- 浏览器使用实际生成的小智页面和模拟接口：相册、裁剪上传、发射入口保留；无 TF 控件、无卡管理请求、无页面脚本错误。两板生成 HTML 的能力差异检查通过。
- 构建产物保存于父目录 `output/sstv-074-integration-dev19/`，附 SHA-256 和源码提交信息。这里的 `.bin` 为应用分区镜像，不是整片擦写包。

## 已知限制

M5 dev.17 的三图显示和缓存后切换由用户实机确认通过。此前 dev.16 多次发射接收结果不一致，最后一次记录为 `sstv_queue_dropped`、85%、393 帧提交、1 帧丢弃；不能宣称发射长期稳定。dev.18 未改动发送队列策略，本项仍待定位。本次完成源码、构建和模拟验证，按用户要求提供刷写页测试入口；没有刷入两台设备，也没有实际发射。小智本轮发射能力未做实机端到端验收。

## dev.19 功能对齐与网页提交

小智补齐三图浏览、中央焦点边框、A/C 选图与 B 确认。使用原有 PSRAM 显示/解码缓冲，不新增完整图片缓冲。实际像素布局、单图/空相册及当前图片身份测试通过，两板构建及完整离线回归通过。在线入口为 `/m5-flasher/sstv-preview/`，主刷写页增加链接；稳定版清单继续为 0.7.74。用户明确要求先不更新 GitHub，因此这是仅经本地检查的测试频道提交，不是正式版发布。

## dev.20 页内裁剪与上传提示

选择图片后自动在相册页内展开 4:3 裁剪区域，支持拖动、缩放、完整画面、重置和取消；点击保存才上传。切换文件会释放旧位图，异步加载只保留最后一次选择；上传中禁用编辑，成功后收起预览，失败保留裁剪并隐藏上传进度条。接收模式开启时明确要求退出接收页，不再误称正在通联/收图。两板共同代码，版本一致。完整离线回归、两板构建及浏览器模拟上传流程/手机布局验证通过。
