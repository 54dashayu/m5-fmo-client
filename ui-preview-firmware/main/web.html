安装后怎么接入？

连接 Wi-Fi 并完成校时 → 选择信任本机签发机构的中继 → 等待显示“已接入”。安装证书成功不等于已经连接服务器。

普通用户无需单独安装根证书。根证书是服务器用来确认“信任谁发证”的依据，不是设备登录凭证。

提交以后做什么？

  1. 保持 M5 联网，按管理员约定的渠道核实呼号。
  2. 管理员在后台审核签发，设备约每分钟检查一次。
  3. 本机验证证书后保存到对应体系，提示已就绪；由你选择切换使用。

关闭网页不影响领取；断网或重启后会继续。通联时延后领取，领取成功也不会打断当前通联。

当前显示的表单只提交给所选签发体系。提交表示同意本机验证并保存该体系的设备证书，不会自动切换当前身份。私钥不离开设备。照片由手机或电脑通过 HTTPS 直接上传，不保存在 M5 内。资料上传后需在 24 小时内让设备联网提交；超时可重新选择照片提交。

支持完整 JSON 证书包或 BI4TES FCRD 文件，无需拆分。含私钥的完整身份备份仅限 USB 管理入口导入；请妥善保管该文件。系统会处理其中的设备证书、中间证书和根证书；单独的根证书不能用于设备登录。
