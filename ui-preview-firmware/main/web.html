安装后怎么接入？

连接 Wi-Fi 并完成校时 → 选择信任本机签发机构的中继 → 等待显示“已接入”。安装证书成功不等于已经连接服务器。

普通用户无需单独安装根证书。根证书是服务器用来确认“信任谁发证”的依据，不是设备登录凭证。

1 · 申请本机设备证书

填写呼号和现有 FMO UID → 上传设备照片 → 审核签发 → 自动安装

填写裸呼号，不带 M. 前缀或 APRS 后缀。请使用你自己的呼号。

不是服务器编号。新设备证书的 UID 由签发系统另外分配，不会使用这里填写的编号。

上传 M5、AI Passport 或其他 ESP32 的清晰实物照片，尽量拍到设备屏幕或标识。照片仅供管理员核实；不需要上传证件或 Wi-Fi 密码。手机/电脑须能访问互联网。

提交以后做什么？

  1. 保持 M5 联网，按管理员约定的渠道核实呼号。
  2. 管理员在后台审核签发，设备约每分钟检查一次。
  3. 本机验证证书后自动安装，并尝试接入所选中继。

关闭网页不影响领取；断网或重启后会继续。通联时延后领取，原有证书在新证书通过验证前保持可用。

在线申请使用 BH1JSS M5 签发体系，提交表示同意本机自动安装该体系为你签发的设备证书。私钥不离开设备。照片由手机或电脑通过 HTTPS 直接上传，不保存在 M5 内。资料上传后需在 24 小时内让设备联网提交；超时可重新选择照片提交。

手动安装设备证书

直接选择管理员后台下载的完整设备证书包。证书必须匹配本机当前申请的公钥和呼号；若已更换使用者，请先在线重新申请。

使用管理员返回的完整 JSON 文件，无需拆分。系统会处理其中的设备证书、中间证书和根证书；单独的根证书不能用于设备登录。

让你的 FMO 服务器接受这套 M5 设备证书，只需添加下面这张根证书。

① 下载 M5 设备信任根证书

BH1JSS M5 Root CA · 公开根证书

这张根证书代表整个 BH1JSS M5 签发体系。每台设备的证书由其授权的中间 CA 签发。

② 添加到你的 FMO 服务器

将下载的 JSON 根证书加入服务器的“受信任根证书”列表；如果使用 SAS，将文件放入实际配置的 --roots-dir 目录，然后重新加载或重启 SAS。

保留已有根证书。添加后，你的服务器即可验证这套体系签发的有效 M5 设备证书；无需逐台添加设备证书。

这是服务器上的操作，不需要在 M5 中导入这张根证书。设备仍须符合服务器的接入规则。
